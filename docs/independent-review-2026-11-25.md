## Stack-level findings (reviewer 4, RAN unless noted)
- Lineage is linear and each tip is an ancestor of the next; the stack is not on `main`.
- Scanner flood: unknown `/v1` paths → 401 then 429 for invalid attempts; the valid token still passes; wrong Host → 421 before the limiter counts. With `HUB_TRUSTED_PROXY_CIDRS` empty, about ten bad requests from anyone make wrong-token and no-token requests answer `429` for five minutes (operator unaffected).
- `/health/ready` was public on any Host and ran `select 1` per request (could keep an auto-paused database awake) and authenticated requests with the database down returned a 500 body containing `connect ECONNREFUSED host:port` → fixed (5 s cache, generic 5xx body).
- `HUB_ALLOWED_HOSTS` unset in production means no host restriction (READ) → startup warning added.
- `worker-main` does not run the role guard (READ); the AI-budget gateway had no integration coverage → added.
- Four `agentsmith_test_*` databases and `rt_*` roles from earlier runs remained on the local loopback Postgres; they are disposable and are cleaned up at the end of this work.
